\chapter{Objetivos}

\section{Objetivo principal}

\begin{itemize}
    \item Validar el comportamiento de un sistema robótico autónomo y desarrollar un prototipo de robot, de modo que realice movimientos en el plano y sea localizable.
\end{itemize}


\section{Objetivos secundarios}

\begin{itemize}
    \item Implementar un sistema de locomoción omnidireccional de 4 ruedas.
    \item Desarrollar un sistema de control capaz de corregir los errores del robot al desplazarse.
    \item Diseñar e implementar una interfaz de usuario para control y monitoreo.
    \item Establecer una comunicación bidireccional con el robot.
\end{itemize}
