\section{Conclusión}

Concluimos en que logramos construir un prototipo funcional con ruedas Omni-wheel, capaz de desplazarse de manera autónoma gracias a la implementación de la estimación de la posición y velocidad en tiempo real, algoritmos de planificación de trayectorias, sistemas de control anidados y resolución de conflictos emergentes. A diferencia de versiones anteriores que dependían de hardware costoso, este prototipo se basa en una solución accesible centrada en el microcontrolador ESP32 y el sistema operativo de tiempo real FreeRTOS, ambos con amplia documentación.

Una de las principales contribuciones del proyecto es la implementación de múltiples niveles de compensación para el control del robot. Esto incluye un controlador PID para regular la velocidad de cada rueda, un modelo cinemático compensado que vincula dichas velocidades con el movimiento global del robot, un seguidor de línea magnética para corregir desviaciones en la orientación, y un filtro de Kalman que estima la posición en tiempo real al fusionar datos de sensores con el modelo teórico. Esta integración permitió una navegación autónoma con errores mínimos, evidenciándose que la diferencia entre la ruta deseada y la real es baja al realizar trayectorias.

Otro aporte esencial fue modelar el espacio mediante Redes de Petri para representar el comportamiento concurrente del sistema, gestionar la ocupación de celdas del mapa y resolver conflictos cuando múltiples robots intentan acceder a la misma posición en determinado momento. Este modelado lo complementamos con un Monitor que implementa colas de cortesía, políticas de prioridad y detección de colisiones, permitiendo escalabilidad y robustez en contextos multi-robot. Asimismo, aportamos soluciones para superar las limitaciones de concurrencia del lenguaje Python, asociadas al Global Interpreter Lock (GIL), mejorando el manejo fino de hilos.

Junto a lo anterior, desarrollamos un sistema de localización basado en el reconocimiento de códigos QR utilizando un microcontrolador ESP32-CAM. El payload de cada código QR contiene la coordenada en la que se encuentra dentro del mapa, de modo que permite al robot determinar su posición relativa respecto al código mediante métodos de fotogrametría. Este enfoque ofrece una solución económica y precisa para la navegación en espacios delimitados.

Para la planificación de trayectorias incorporamos el algoritmo A*, el cual opera sobre el modelo del mapa, que calcula la trayectoria óptima, considerando otros robots y obstáculos del mapa.

Las tareas de monitoreo y envío de comandos las llevamos a cabo mediante el desarrollo de una interfaz de usuario en conjunto a una comunicación bidireccional inalámbrica.
